# nuScenes data notice

The experiment was conducted using JPEG images derived from the **nuScenes**
dataset created by Motional (formerly nuTonomy). The images are not original
works of this repository's authors and are intentionally not distributed here.
Any local `saved/` directory is excluded by `.gitignore`.

Use and redistribution of the images and data derived from nuScenes are subject
to the current [nuScenes Dataset Terms](https://www.nuscenes.org/terms-of-use-commercial)
and the Creative Commons license identified by those terms. Users are responsible
for reviewing and complying with both before using the images, particularly for
commercial activities.

The nuScenes terms require attribution and prohibit implying endorsement by or
affiliation with Motional. The dataset should be cited as:

> Holger Caesar, Varun Bankiti, Alex H. Lang, Sourabh Vora, Venice Erin Liong,
> Qiang Xu, Anush Krishnan, Yu Pan, Giancarlo Baldan, and Oscar Beijbom.
> “nuScenes: A Multimodal Dataset for Autonomous Driving.” CVPR, 2020.

This notice applies to the dataset images. It does not assign a license to the
source code, annotations, prompts, or model outputs in this repository.
